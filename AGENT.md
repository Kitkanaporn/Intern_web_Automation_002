# Project
AI-Assisted SDLC Workflow Automation Platform

## Project Overview
This is AI platform to help some part in SDLC workflow thst they do by themself such as
- sent assignment to each department 
- divide main-task to sub-task
- notification to each department when has some change
This project use Next.js , TypeScript , tailwind , CSS , Prisma and PostgreSQL to make full-stack web application
